## What is included
* Ruby
  * Basic POI data collection (e.g. Address)
  * Advanced POI data collection (e.g. Hair Color)
* Finder
  * [IDCrawl](https://www.idcrawl.com/) Support
  * [ThatsThem](https://thatsthem.com/) Support
  * [TruePeopleSearch](https://www.truepeoplesearch.com/) Support
  * [WhitePages](https://www.whitepages.com/) Support
‎

## Requirements
* Python

## Usage
```
git clone https://github.com/JessicaEmberlyOfficial/Ruby
```

```
cd Ruby
```

```
python run.py
```

### Usage Notes
```
You can run the (*.txt) file contents, post-creation, into Stra1n, and essentially encrypt your file if you customized your Stra1n's (*.ini) file.
```
